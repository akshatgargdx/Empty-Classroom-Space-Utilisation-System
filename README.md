# Empty-Classroom-Space-Utilisation-System
ECS: Empty Classroom System 🏫  A real-time full-stack dashboard for tracking classroom availability at GEU.  Live Logic: Auto-syncs with college timetables (8AM–4PM).  Tech: React, Node.js, Express, and SQLite.  Security: JWT-based login.  Key Feature: Dynamic status cards (Red/Green) with 100% responsive UI.
